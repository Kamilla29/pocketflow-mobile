# Product scope

PocketFlow is a fictional mobile companion for the LoanFlow portfolio application.

Implemented local scope:

- loan overview;
- application status;
- repayment progress;
- payment schedule;
- application checklist;
- recent product activity;
- pull-to-refresh;
- persisted notification/accessibility/appearance preferences;
- system/light/dark theme selection;
- deep-link routes;
- loading and recoverable error states;
- app-level error boundary.

Explicitly out of scope:

- real authentication;
- identity verification;
- banking credentials;
- document uploads;
- credit scoring;
- payments or transfers;
- production push notifications;
- analytics or tracking.
